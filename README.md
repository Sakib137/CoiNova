## 📖 Overview

**CoiNova** is crafted for the next generation of digital asset investors and DeFi natives. Built entirely from the ground up using **Flutter** and **Dart**, it combines an ultra-luxurious **Obsidian Cyber Glassmorphism** visual language with high-performance financial tooling:

- 📊 **Real-time Portfolio Tracking**: Live balance valuation, asset distribution donut graphs, and 24-hour profit/loss analytics.
- 🤖 **Nova AI Copilot**: Autonomous intelligence monitoring portfolio risk profiles, scouting high-yield liquid staking opportunities, and detecting low-gas transaction windows.
- 🔄 **Multi-Chain DEX Terminal**: Interactive swap terminal featuring real-time DEX routing visualization (Uniswap v3, Raydium, 1inch), slippage tolerance controls, and biometric slide-to-confirm execution.
- 📈 **Bespoke Financial Visualizations**: 100% custom-painted interactive bezier curve price charts with scrubbable crosshairs, dynamic sparklines, and a Fear & Greed sentiment gauge—with zero heavy third-party charting bloat.

## ✨ Key Features

### 🌌 Obsidian Cyber Aesthetic & Glassmorphism
- Custom deep obsidian surface hierarchy (`#080A10` background, `#0E121E` surface, `#141A29` elevated cards).
- Dynamic ambient aurora glow effects and frosted glass blur overlays.
- Bento-grid asset highlights and high-contrast neon accents (Electric Purple, Neon Indigo, Cyber Cyan, Emerald Gain, Crimson Loss).

### 🤖 Nova AI Copilot (DeFi Intelligence Sentinel)
- **Portfolio Health Scoring**: Instant risk-tier assessment (e.g., 98/100 Optimal) and diversification audit.
- **Actionable Yield Signals**: Intelligent notifications for liquid staking (e.g., Jito MEV rewards, +7.8% APY).
- **Gas Fee Radar**: Predictive timing to execute on-chain transactions during optimal gas windows.

### 🔄 Multi-Chain DEX Swap Terminal & Route Visualizer
- Instant token swaps across **Ethereum**, **Solana**, and **Bitcoin** ecosystems.
- **Animated DEX Route Visualizer**: Displays hop-by-hop execution pathways (e.g., `ETH` ➔ `Uniswap v3 (0.05%)` ➔ `Raydium Router` ➔ `SOL`).
- Comprehensive quote breakdown: Expected output, estimated network gas, slippage tolerance (0.1%, 0.5%, 1.0%), and price impact.
- Quick token flipper with smooth 180° rotation animation.

### 🔒 Slide-to-Confirm & Biometric Transaction Security
- Intuitive drag-to-confirm slider preventing accidental trade execution.
- Smooth transition into a cryptographic transaction receipt modal complete with transaction hash, explorer links, and timestamp.

### 📈 Interactive Scrubbable Charts (Native CustomPainter)
- Smooth cubic Bezier curves with gradient fills and live animated rendering.
- Scrubbable crosshairs displaying precise asset price, timestamps, and gain/loss percentage at any touchpoint.
- Multi-period selection: `1H`, `24H`, `1W`, `1M`, `1Y`, `ALL`.
- Compact mini sparklines integrated across all token list rows and bento cards.

### 🍩 Interactive Portfolio Donut Allocation
- Bespoke multi-segment circular asset distribution graph.
- Real-time percentage recalculation as asset values fluctuate.
- Toggle between total holdings breakdown and comprehensive transaction ledger.

### 🧭 Market Sentiment & Fear / Greed Gauge
- Macro crypto market sentiment needle gauge (Extreme Fear, Fear, Neutral, Greed, Extreme Greed).
- Multi-category market filtering: **All**, **Gainers**, **Losers**, **Layer 1**, **DeFi**, and **AI Tokens**.
- Live search engine filtering by asset name, ticker symbol, or contract address.

### 📲 Instant Send & Receive with Native QR Matrix
- Integrated **custom-painted QR code generator** for wallet addresses (zero third-party dependencies).
- One-tap address and ENS copy (`alex.eth`), network switcher, and share sheet.
- Fast recipient address input, gas fee prioritization (Standard, Fast, Instant), and balance validation.

## 🎨 Design & UI Philosophy

CoiNova adheres to the highest modern mobile and web design standards:

| Principle | Implementation in CoiNova |
| :--- | :--- |
| **Color Harmonization** | Tailored dark-mode palette using HSL-calibrated hues for optimal OLED contrast and reduced eye strain. |
| **Depth & Layering** | Frosted glass containers (`BackdropFilter`), semi-transparent borders (`0x1AFFFFFF`), and layered radial glow shadows. |
| **Micro-Interactions** | Haptic slide-to-confirm, bouncing physics scroll views, smooth cross-fades, and rotating swap triggers. |
| **Zero-Bloat Visuals** | All charts, rings, QR codes, and meters are authored with pure Flutter `CustomPainter` APIs for 60/120 FPS performance. |

## 🏛️ App Architecture

The repository follows a clean, modular, and maintainable layered architecture:

```
lib/
├── data/                       # Static mock data, seed states & ticker generator
│   └── mock_crypto_data.dart   # Sample portfolios, token stats, historical txs
├── models/                     # Type-safe immutable domain data models
│   ├── crypto_asset.dart       # Asset definitions, sparklines, categories
│   └── transaction_model.dart  # Transaction history, hashes, status
├── screens/                    # Top-level screen views and navigation flows
│   ├── asset_detail_screen.dart # In-depth market stats, chart scrubbing, trade actions
│   ├── home_screen.dart        # Main dashboard, bento grid, quick actions, balance ticker
│   ├── main_nav_screen.dart    # Glass bottom navigation dock & indexed page stack
│   ├── markets_screen.dart     # Market intelligence, fear/greed meter, token discovery
│   ├── onboarding_screen.dart  # Engaging introduction with cosmic rings animation
│   ├── portfolio_screen.dart   # Donut chart asset allocation & transaction history
│   ├── receive_sheet.dart      # Custom QR code display, address copy & network selection
│   ├── send_sheet.dart         # Transfer wizard, gas speed selection, address input
│   ├── settings_screen.dart    # Security toggles, biometrics, currency switcher, network
│   └── swap_sheet.dart         # Non-custodial DEX swap interface & execution
├── theme/                      # Styling tokens, typography, gradients & themes
│   ├── app_colors.dart         # Color definitions, glass gradients, brand colors
│   └── app_theme.dart          # Dark theme specification & text styles
└── widgets/                    # Reusable, standalone UI components & painters
    ├── action_button.dart      # Quick action circular buttons (Send, Receive, Swap)
    ├── ambient_aurora_background.dart # Atmospheric background gradient shader
    ├── bento_asset_card.dart   # Bento-style asset highlight cards with sparklines
    ├── cosmic_rings_painter.dart # Concentric orbital background animation
    ├── dex_route_visualizer.dart # Multi-hop swap route visualizer with pulse effects
    ├── fear_greed_meter.dart   # Radial sentiment gauge with pointer indicator
    ├── glass_container.dart    # Reusable backdrop filter frosted glass widget
    ├── interactive_chart.dart  # Scrubbable bezier chart with crosshair & tooltip
    ├── nova_copilot_sheet.dart # AI intelligence modal with health score & alpha alerts
    ├── portfolio_donut_chart.dart # Custom-painted asset distribution donut chart
    ├── qr_code_painter.dart    # Native matrix QR code renderer
    ├── slide_to_confirm.dart   # Interactive slider with haptics & progress tracking
    ├── sparkline_chart.dart    # Lightweight mini sparkline painter
    ├── swap_success_sheet.dart # Confetti transaction completion receipt modal
    └── token_tile.dart         # High-density token list row with prices & 24h change
```

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed on your development machine:
- [Flutter SDK](https://docs.flutter.dev/get-started/install) (`>= 3.12.0`)
- [Dart SDK](https://dart.dev/get-dart) (`>= 3.0.0`)
- An IDE with Flutter plugins installed: [VS Code](https://code.visualstudio.com/) or [Android Studio](https://developer.android.com/studio)
- Device simulators or physical devices:
  - iOS Simulator (requires Xcode on macOS)
  - Android Emulator (requires Android Studio)
  - Chrome (for Flutter Web)
  - macOS / Windows / Linux desktop environments

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Sakib137/CoiNova.git
   cd CoiNova
   ```

2. **Install Flutter dependencies:**
   ```bash
   flutter pub get
   ```

3. **Verify Flutter environment:**
   ```bash
   flutter doctor
   ```

4. **Run the application:**
   - **For Mobile (iOS / Android):**
     ```bash
     flutter run
     ```
   - **For Web:**
     ```bash
     flutter run -d chrome
     ```
   - **For macOS Desktop:**
     ```bash
     flutter run -d macos
     ```

## 🔌 Connecting to Live Web3 & Market APIs

CoiNova is pre-configured with a robust mock data layer (`lib/data/mock_crypto_data.dart`) with built-in simulated price fluctuation timers. To connect real-world data sources:

1. **Live Market Prices & Charts**:
   - Integrate the [CoinGecko API](https://www.coingecko.com/en/api) or [Binance REST / WebSocket API](https://binance-docs.github.io/apidocs/spot/en/).
   - Replace `MockCryptoData.getAssets()` with an HTTP service provider or Bloc/Riverpod repository.

2. **On-Chain Web3 Wallets & Swaps**:
   - Utilize [web3dart](https://pub.dev/packages/web3dart) or [reown_appkit](https://pub.dev/packages/reown_appkit) (WalletConnect v2).
   - Hook the `SwapSheet` execution callback to 1inch or Uniswap v3 smart contract routers.
